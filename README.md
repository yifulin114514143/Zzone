# Zzone v1.0 · 绝区零全生态信息聚合站

专注、轻量的《绝区零》多信源实时信息聚合站（Web + PWA），直连**国服官网 + HoYoverse 国际官网**双源并预留 X / B站 / 米游社 / 米游铺多平台号池接入。

## v1.0 核心板块（5 大频道）

1. **发现**：只聚焦即将到来与最新的重磅内容——3.4 新版本、2026 杭州 FES & ZLIVE 双倒计时、最新跨界联动、最新周边上新与最新官方公告。
2. **资讯**：全网实时资讯流，支持按来源平台筛选（国服官网 / 国际官网 / X / B站 / 米游社）、仅看官方直连、频道过滤与最新/热度排序。
3. **活动**：官方大型活动（杭州 FES、ZLIVE、武汉欢乐谷 × 雅迪联动、KFC 联动、东京妄想天使演唱会）与同人 Only 展，全活动支持多图画廊、长图原图放大与 `.ics` 日历导出。
4. **周边**：米游铺版本上新、日常定期上新与跨界联名周边（如雅迪联名电动车），全商品多图详情展示 + 种草心愿单。
5. **信源**：多平台采集监控、号池调度控制台（`server/pool.mjs`）、有效兑换码与本地收藏。

## 本地运行与一键云端部署

```bash
# 本地启动
pnpm install && pnpm run build && pnpm run start

# 云服务器 Docker 一键启动（支持 server/data/store.json 自动持久化）
docker compose up -d --build

# 绑定专属域名并自动签发 HTTPS 证书
cp Caddyfile.example Caddyfile && caddy start
```
